## Overview
Nova Style is a modern fashion storefront website inspired by
online fashion stores. It was created to practice HTML and CSS
by building a simple, attractive, and user-friendly shopping
interface.

The website displays fashion products in a responsive grid
layout and includes basic navigation and interactive styling.

## Features
- Responsive navigation bar
- Fashion product grid
- Product cards
- Home and Products navigation links
- Shopping Cart button
- Dark Mode option
- Hover and transition effects
- Clean and modern fashion design
- Fashion product categories

## Technologies Used
- HTML5
- CSS3

## Purpose
This project was created as part of an HTML and CSS assignment
to practice creating and styling a fashion storefront website.

## Design
The website uses CSS to create a clean and modern fashion-store
appearance. Products are arranged using a grid layout, while
colors, spacing, buttons, navigation, and hover effects are
used to improve the overall user experience.
